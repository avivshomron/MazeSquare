Privacy Policy – Maze Square

Effective Date: 09/05/2026

1. Information We Collect

Maze Square collects limited information necessary for game functionality:

  • Technical and diagnostic data provided by Firebase services

2. How We Use Information

We use the collected data to:

  • Save and synchronize game progress

  • Improve game stability and performance

3. Local Storage

Some data such as settings and progress may be stored locally on your device using Unity storage systems.

4. Online Services

The game uses Google Firebase services, including:

  • Firebase Authentication (anonymous login)
  • Firebase Firestore (cloud data storage)
  • Additional Firebase services included in the app build

5. Advertising

The current version of Maze Square may include simulated advertising systems. If real advertising services are added in future versions, this policy will be updated accordingly.

6. Data Sharing

We do not sell personal data. Data is processed through trusted third-party services such as Google Firebase solely to provide game functionality.

7. Children’s Privacy

Maze Square may be used by children. Users are advised not to enter real personal information in the username field.

8. Security

All data transmission is handled securely through encrypted connections provided by Firebase and platform services.

You may stop using the application at any time to remove locally stored data.
